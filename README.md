# Dotfiles

## Dependencies

- **nvim**: Neovim >= 0.12
- **kitty**: [Fira Code](https://github.com/tonsky/FiraCode) fonts
- **niri**: [Noctalia](https://github.com/noctalia-dev/noctalia-shell) shell
- **fish**:
    - [eza](https://github.com/eza-community/eza) replaces ls
    - [fastfetch](https://github.com/fastfetch-cli/fastfetch) greeting
    - [starship](https://github.com/starship/starship) theming
    - [zoxide](https://github.com/ajeetdsouza/zoxide) replaces cd
